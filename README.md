# Dictionary1: Python Dictionary Fundamentals

## 🎯 Objective
Learn and practice Python Dictionary data structure with real examples and operations.

## 🛠️ Tools & Technologies
- **Language**: Python 3.x
- **Platform**: Jupyter Notebook
- **Concepts**: Key-Value pairs, .get() method, Dictionary operations

## 📚 Topics Covered
1. **Creating Dictionary** - `student = {"name": "Rom", "age": 15, "marks": 34}`
2. **Accessing Values** - Using keys and `.get()` method
3. **Real-life Examples** - Student records, data mapping

## 💻 Code Example
```python
student = {
    "name": "rahul",
    "age": 15,
    "marks": 87
}
print(student.get("age"))   # 15
print(student["marks"])     # 87
